# 拾光 · 飞书工作汇总 Agent

一个优先跑通闭环的本地 Demo：读取指定飞书群的消息，生成**个人向上工作汇报**或**项目汇报**，支持日报、周报、月报和 Markdown 下载。

当前版本 **0.3.0**：汇报配置专项 M01—M08 已完成实施和本轮验收。最终检查和数据保全结果统一记录在[汇报配置验收记录](docs/MODEL_CONFIGURATION_VALIDATION.md)，不代表已完成连续多日真实试用。

后续安排见[下一轮任务与待设计事项](docs/NEXT_ITERATION_PLAN.md)（2026-10-24，已记录，按用户要求暂不执行）。本机启动、迁移和维护见[本地部署使用指南](docs/LOCAL_DEPLOYMENT.md)。

Python 标准库 + SQLite + 原生网页，**无第三方依赖、无构建步骤、无需云服务器**。不配置模型也能体验全部流程；默认生成基于消息的分类摘录，可选模型润色草稿。

## 一分钟启动

需要 Python 3.11 或以上版本。在工程目录运行：

```powershell
python run.py
```

Windows 也可双击 `start.bat`。打开 [本地工作台](http://127.0.0.1:8765)，点击“载入演示消息”，选择群聊与周期，然后“同步并生成”。个人汇报还需选择“示例用户 · 林晨”。示例是明确标记的虚构数据，不代表真实飞书已经接通。

工作台提供消息预览、群聊多选、项目／个人切换、常用设置、日期与覆盖提示、一键同步生成、用途与表达配置、复制、下载和最近 100 份报告列表。数据、本机昵称、配置快照和常用设置保存在 `data/work_summary.sqlite3`，重启后保留。日常操作见 [使用说明](docs/USAGE.md)。

## 0.3.0：按用途组织汇报

保留经典结构，新增 **PPP 进展／计划／问题、项目进展、工作复盘**三套内容模板。五种用途提供建议组合：

| 用途与场景 | 默认模板与框架 |
| --- | --- |
| 进展同步（日常同步） | PPP ＋ BLUF，先给人工确认的要点 |
| 提出建议（重点建议） | PPP ＋ PREP，观点、理由、例证、重申观点 |
| 请求决策（方案请示） | 项目进展 ＋ SCQA，背景、困难、问题、建议答案 |
| 风险升级（风险求助） | 项目进展 ＋ SBAR，现状、背景、判断、请求 |
| 经验复盘（阶段复盘） | 工作复盘 ＋ What／So What／Now What |

在“汇报用途”选择用途，点击“配置表达方式”补充本次材料、调整章节顺序，再生成候选预览。**候选最长有效 30 分钟（最多保留 20 份候选，较早候选可能提前失效），点击“保存此预览”后才进入汇报记录并可审阅、复制和下载**；过期或服务重启后需重新预览。经典结构未配置用途时沿用原有直接生成方式。

“保存用途偏好”只保存当前来源的用途、模板、框架、章节顺序和补充记录显示选项；不保存本次背景、判断、请求等材料或重点事项选择。缺少关键材料时明确显示“待补充”，不会从群消息编造收益、根因、负责人或承诺。人工陈述与原始事实分开标明，风险章节不可隐藏。

打开已保存的规则稿后，可“按用途重组并另存”：使用该报告已有的事项、证据和覆盖快照，预览后另存版本，不重新读取当前消息缓存或覆盖原稿。按条审阅仍可排除、恢复、改写和新增；所选支撑条目变化时会提示重新核对人工陈述。AI 稿、自由编辑稿和缺少结构化快照的旧稿不支持结构重组。新组合采用免费规则与人工材料；AI 润色仍只在“经典结构（保持现有方式）”中使用。

本专项没有新增系统软件、第三方依赖或飞书权限。M09—M10 为后续框架扩展，原第 13—16 项保持原范围与未执行状态。细节见[配置专项与状态](docs/MODEL_CONFIGURATION_PLAN.md)。

可直接查看已生成的虚构示例：[个人日报](examples/personal-daily.md)、[项目周报](examples/project-weekly.md)、[项目月报](examples/project-monthly.md)。示例日期为 2026-10-19；当天是周一，周报仅有当日数据，并不表示整周已结束。

## 接入你的飞书

完整步骤见 [飞书接入指南](docs/FEISHU_SETUP.md)。

项目曾在一个已授权内部测试群验证消息读取及个人、项目的日报／周报／月报闭环，真实样本仅覆盖单日；多日复杂场景使用隔离模拟数据，不代表真实多日工作已验收。代码仓库不包含测试人员身份、群标识、原消息或导出报告。新使用者需配置自己的应用，并按指南完成首次验证。脱敏后的验证范围见 [配置记录](docs/SETUP_PROGRESS.md)。

新环境的配置步骤：

1. 在飞书开放平台创建**企业自建应用**，启用应用机器人。申请 `im:chat:read`、`im:message:readonly`、`im:message.group_msg`；完成企业审批、发布，并将机器人加入测试群。
2. 复制配置示例，在本机填写 App ID 和 App Secret：

   ```powershell
   if (!(Test-Path .env)) { Copy-Item .env.example .env }
   ```

   ```dotenv
   FEISHU_APP_ID=你的应用ID
   FEISHU_APP_SECRET=你的应用密钥
   ```

3. 重启服务，在页面选择“飞书群聊”，选中测试群和周期，点击“同步并生成”。首次个人汇报先“仅同步消息”，从已同步发送者中选择自己的 ID；仅使用本人发言，其他人提到你的工作不会自动纳入。

个人模式可展开“核对成员标识”确认本人，再在“报告姓名显示”选择“飞书姓名（默认）”或“自定义昵称”，点击“保存姓名设置”。切回飞书姓名会保留原昵称，只有明确选择昵称模式并保存后才启用。飞书姓名尚未读取时，页面说明实际使用的本机备注、原消息姓名或稳定标识。“成员与事项”仍可为其他成员填写本机备注；这些显示设置不会切换本人身份或修改飞书资料。完整成员标识保留在核对附录，旧报告保持生成时的内容。

自动姓名读取需额外授予应用身份权限 `im:chat.members:read`，已在授权测试群验证。新环境不会继承该授权，需自行申请并核对结果。本人身份、常用设置、原报告和原快照不因显示方式变化而改写。飞书接口返回的 `name` 不保证等于群昵称，详见[接入指南](docs/FEISHU_SETUP.md)。

设置好后点击“保存为常用设置”。下次打开会恢复同一来源的群、本人、周期与视角，日期取当天；匹配常用设置时可从首屏“一键生成常用汇报”。日期与 AI 开关不存入偏好，AI 需要对每次生成手动开启。

经典报告采用“本期成果、工作进展、风险与待协调、下一步计划”四节，新模板按所选结构组织相同事实分类。个人模板减少重复姓名，项目模板保留每项作者；补充记录、统计说明与来源默认折叠，复制和下载仍包含完整内容。点击引用编号核对原话后，可用“按条审阅”调整取舍与分类、改写或增加人工条目，再“另存审阅稿”。排除的条目保留，可在后续审阅版本恢复；消息数仍指原稿引用范围，人工内容有明确标记。AI 报告、自由编辑稿和缺少结构快照的旧稿继续使用“自由编辑并另存修订稿”；引用不能自动证明改写或新增内容。

更新提示和操作回执位于工作台页面。发现版本或其他标签有变化时，点击“主动更新此页面”；有未保存修改时可先保留编辑，保存后再更新。“操作记录”只解释本工作台处理的同步、设置、报告与维护操作，版本说明列出本工程功能及依赖变化。

权限与接口依据：[飞书历史消息 API](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/im-v1/message/list)、[官方群列表权限说明](https://github.com/larksuite/cli/blob/main/skills/lark-im/references/lark-im-chat-list.md)。本项目使用兼容的自建应用 `tenant_access_token/internal` 令牌接口。

无需公网地址或消息回调。群自定义机器人的发送 Webhook 无法代替上述读取授权。凭据只写在本机 `.env`，不要发到聊天或提交到仓库；`.env` 和 `data/` 已加入忽略规则。

## 可选：启用模型整理

默认不调用模型，适合先验证消息读取是否可靠。需要更自然的语言汇总时，在 `.env` 填写支持 `/chat/completions` 的模型服务：

```dotenv
LLM_BASE_URL=https://你的模型服务地址/v1
LLM_API_KEY=你的模型密钥
LLM_MODEL=该服务支持的模型名称
```

重启后，先选择“经典结构（保持现有方式）”，再在生成前勾选 AI 整理；新的用途组合暂不支持 AI。**只有勾选后，所选消息才会发送到该模型服务，并按服务规则计费**。接口需接受 `model`、`messages` 并返回 `choices[0].message.content`。本机服务可使用 `http://127.0.0.1:端口/v1`；若不验证密钥，可填一个本机占位值。远程服务必须使用 HTTPS。

单次模型输入上限为 40000 字符。超出时明确报错，不静默截断；可以缩小群范围，或使用无此模型输入限制的本地摘录。模型失败时不会冒充 AI 成功，也不会自动换成另一种模式。每条实质内容要求有效消息引用，引用只能辅助核对，不能证明模型对原文的理解正确。

## 报告口径与首版边界

- 日期统一按北京时间：日报为自然日，周报从周一到周日，月报为自然月。同步查询使用左闭右开时间区间。
- 项目汇报汇总选定群；个人汇报只筛选明确选择的发送者 ID。未调用通讯录，不会自动验证所选 ID 就是本人。
- 导入文字与富文本中可提取的文字；不识别图片、附件、卡片、合并转发和话题回复。机器人只能读取其权限和可见范围允许的数据。
- 消息与报告区分 `demo` 和 `feishu`，绝不混合生成。报告附消息编号、发送者、时间、群名和消息标识，便于核对。
- 同步成功才保存覆盖范围，包括成功读取但没有消息的时段。范围未覆盖全部所选群和统计周期时，报告明确标注为部分消息草稿；后续新增消息需要再次同步。
- 重复同步会去重，并刷新所选群和时间段，移除该范围内不再返回的旧缓存。任一群同步失败时本批不更新，防止一半成功造成误解。
- 同步在后台显示进度；网络、限流或暂时服务故障只做有界重试，权限错误不重复请求。状态暂时无法确认时使用“继续查看进度”，不要重复提交。
- 消息依据保存为报告生成时的快照；历史报告缺少结构化快照时只展示原有来源附录，不从当前缓存重建。事项关联由使用者确认，不会跨作者自动合并。
- 默认备份位于 `data/backups/`，包含本机消息、报告、备注、修订和关联等数据库内容，不包含 `.env`。恢复只接受本机备份列表中的有效备份，恢复前会自动备份当前数据。
- 操作回执单独保存在 `data/operations.sqlite3`，不随主库备份恢复而回退；记录范围仅限本程序，不保存消息或修订正文、密钥及任意系统命令，不监控电脑上其他软件的安装。
- 报告是可审阅的草稿。规则分类不等于语义理解；AI 也可能错误归纳。使用前核对归属、完成状态和完整性。
- 首版仅供单人本机使用，服务绑定 `127.0.0.1`。未实现多人登录、公网部署、后台定时、自动发送、云文档或多维表格读取。

新环境没有配置应用凭据时，不能视为已接通该环境的飞书。先用测试群完成指南中的逐条对照，再导入工作消息。
