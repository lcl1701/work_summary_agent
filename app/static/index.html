本地配置

连接你的工作空间

先用演示数据体验。连接飞书后，可读取应用机器人已加入的指定群聊。

  1. 创建飞书企业自建应用

    开启机器人能力，按项目 README 申请读取群列表和群历史消息所需权限，发布应用并将机器人加入目标群。

  2. 填写本机配置

    将项目的 .env.example 复制为 .env，填写 FEISHU_APP_ID 与 FEISHU_APP_SECRET，重启服务。

  3. 选择群聊并同步

    切换到飞书群聊，明确选择群和时间范围，再手动同步。个人汇报需选择对应发言人。

AI 润色为可选功能

不配置模型也能整理汇报。需要 AI 时，在 .env 中按 README 填写兼容接口与模型信息；启用后，所选消息会发送给你配置的模型服务。
