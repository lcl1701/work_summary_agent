# 飞书配置与验证进度（脱敏记录）

更新时间：2026-10-24。此文仅保留项目既有联调的授权范围、功能结果与验证边界；不记录人员姓名、昵称、租户名称、群名、应用 ID、用户 ID、群 ID 或工作原话。以下结果不代表新环境已获授权或已接通飞书。

## 应用接入与首次联调

- 经使用者确认，创建独立企业自建应用，启用机器人，以本人为初始测试可用范围，凭据仅保存本机 `.env`。
- 最初申请三个应用身份权限：`im:chat:read`、`im:message:readonly`、`im:message.group_msg`。没有申请全通讯录、云文档、表格或发送消息权限。
- 已完成应用发布并核对授权生效，通过真实接口验证凭据、访问令牌与群列表读取。
- 首个外部测试群无法按当前应用配置添加机器人，后改用内部测试群完成 Demo；不能据此承诺所有外部群可用。
- 使用者手动邀请机器人入内部测试群后，完成消息同步与个人发送者核对，不通过工作内容猜测本人身份。
- 真实样本仅覆盖单日、两位发送者共 5 条文字消息；个人范围为已核对本人的 1 条，项目范围为全部 5 条，并保留作者归属。
- 完成个人、项目的日报／周报／月报六种报告生成与下载检查，下载内容与保存内容一致。
- 一条包含多项工作的编号消息可按事项拆条，同时保留同一原消息引用；报告消息数量仍按原消息计数。
- 验证本机昵称、折叠身份附录、常用设置恢复、覆盖提示及一键生成；改名不改写原消息、既有报告或来源快照。
- 联调导出与原始证据仅保存在已忽略的本机数据目录，代码仓库不包含该真实样本。
- 联调未向飞书发送消息，未调用收费模型；后续只按单独确认增加下述群成员读取权限。

## 本机功能完善

1. 缓存群成员名称，支持任意已同步成员的本机备注和稳定未命名标识；备注不改变原发送者身份。
2. 区分完成、进行中、风险、计划、否定和等待验收等工作状态；不明确内容保留为补充记录。
3. 保存报告生成时的来源快照，引用可核对原话、作者、群与时间；缺少快照的旧稿不从当前缓存重建历史依据。
4. 支持人工编辑并另存修订，保留原稿与依据；人工新增内容不会因沿用引用编号而自动获得事实证明。
5. 同步与生成提供后台进度、有界重试和重复提交保护；权限问题不会反复重试，状态未知时可继续查看进度。
6. 支持 SQLite 一致性备份、校验和恢复；恢复前创建安全副本，不恢复 `.env`。
7. 支持按周期、日期、群和本人核对消息数及查询覆盖；0 条消息不等于没有工作。
8. 支持人工关联同一作者的相关消息，周报和月报展示事项时间线；不跨作者自动合并或删除消息。

## 群成员名称授权与验证

- 仅有三个基础读取权限时，群成员接口曾返回 `99991672`；经单项确认后增加应用身份权限 `im:chat.members:read` 并核对生效。
- 在授权内部测试群完成两位成员的名称读取。公开文档不替换展示接口返回的真实姓名，避免将示例名称误认为真实响应；返回的 `name` 不保证等于群昵称。
- 核对本人档案、成员备注、常用设置、原始消息、原有报告与来源快照保持原样。没有为名称读取申请全企业通讯录权限。
- 名称刷新后重新检查六种报告的作者归属、消息数、快照条数和下载一致性；项目各 5 条、个人各 1 条。
- 原导出与核对清单留在本机数据目录，公开仓库只记录验证范围。

## 后续使用与验证边界

新使用者按 [接入指南](FEISHU_SETUP.md) 配置自己的应用，在工作台选择自己获准访问的群、实际消息日期和周期，同步后生成。个人报告须选择经客户端核对的本人发送者，项目报告汇总所选群。

既有真实联调仅证明一个内部群、单日、两位成员的小样本闭环，不能证明真实多日工作、整月成果或其他群均已验收。多日、多群和周期边界使用隔离模拟数据重放，见 [本地重放验收](SCENARIO_VALIDATION.md)。持续真实使用、模型质量与费用仍需另行验证。

功能操作见 [使用说明](USAGE.md)。自动检查使用 `python -m unittest discover -s tests -v`；最终结果和验证边界由 [验证记录](VALIDATION.md) 统一记录。
