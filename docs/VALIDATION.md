## 第 3、4 项报告与常用流程验证

- 本地模板统一为本期成果、工作进展、风险与待协调、下一步计划；不明确状态保留补充记录。个人单作者条目省重复姓名，项目保留作者，不虚构结果、收益或后续安排。
- 当前真实的本人编号清单仍为 1 条消息，生成三项成果、一项补充；另一成员的缺陷记录在项目风险章节，个人不混入他人发言。
- 模型使用模拟响应验证固定章节、合法引用、成果归属和严格空状态；缺节、未知引用、无引用事实、服务错误均不保存报告，也不静默降级。
- 常用群、本人、周期、视角与最近来源按来源存于本机；区分未保存与明确空选择。日期、AI 开关和凭证不进入偏好。
- 实际页面保存飞书内部测试群、本人“船长”、个人日报，刷新后恢复选择；日期为当天，AI 关闭。
- 实际页面一键个人日报处理 5 条真实消息，报告引用本人 1 条；一键项目日报处理并引用全部 5 条。覆盖与历史列表同步刷新。
- 隔离本机 HTTP 验证失败同步不从旧缓存生成、非法参数不先读取远程、下载与生成一致、来源恢复和跨站限制；生成阶段失败明确指出消息已同步但报告未完成。
- 顶部可见快捷入口仅对匹配且可用的常用设置显示，不在页面加载时自动同步或生成。
- 六份真实 Markdown 和三个明确标记的虚构示例均已更新为新模板；示例在隔离数据库生成，真实消息与常用设置保持原样。下载、保存与生成的正文逐字一致。
