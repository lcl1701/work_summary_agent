## 已确认的决策树

```text

├─ 信息入口：指定飞书群（已确认）
│  ├─ 应用机器人已加入这些群（已确认采用该方案）

└─ 运行与交付：本地手动生成、预览和下载（已确认）
   ├─ 不启用定时任务
   └─ 不自动向飞书发送
```

## 工程默认值，不冒充用户回答

- 本地规则摘录默认可用，模型为可选项，以减少启动成本；模型质量与费用取决于所配服务。
- 周报从周一开始，月报按自然月，时区为 `Asia/Shanghai`。
- 同一份报告可选择一个或多个群；首版项目范围由群选择决定。
- 使用者手动核对本人 ID。未读取通讯录，也未通过个人 OAuth 验证其本人身份。
- 本地保存消息与报告；演示和飞书数据显式隔离。当前 Demo 不承诺企业生产环境的数据治理能力。
- 输出 Markdown；汇报是有消息依据的草稿，仍需使用者审阅事实、措辞与完整性。

## 尚未验证的外部条件

这些是接入步骤，不是尚未回答的产品范围问题，也不需要把密钥发送到对话：

- 企业是否允许创建自建应用，申请的读取权限能否获批并发布生效。
- 机器人是否已经被加入目标群，目标消息时间范围是否可被应用实际读取。
- 本机 `.env` 中的凭证是否有效，网络能否访问飞书服务。
- 用户是否选用模型、所配模型服务的网络及接口兼容性；默认不依赖此项。

## 延后决策

自动投递的接收人和审核方式、定时频率、文档/任务/表格来源、多人部署、存储保留周期和报告模板个性化，在首份真实报告验证后再讨论。当前实现不暗含对这些功能的授权或承诺。
