# 本地部署与使用

更新日期：2026-10-24。适用版本：0.3.0，Windows 单人本机使用。

## 运行要求

将工程放在自己选择的本地目录，按 [飞书接入指南](FEISHU_SETUP.md) 配置自己的应用。代码仓库不包含开发者的凭据和消息数据，首次运行不能视为已接通飞书。启动后打开 <http://127.0.0.1:8765/> 即可进入工作台。

工程仅需 Python 3.11 或以上，使用标准库、SQLite 和原生网页。无需安装 Java、Node.js、Docker、独立数据库或额外 Python 包。

## 启动和停止

1. 打开工程文件夹，双击 `start.bat`。
2. 保持启动窗口运行，在浏览器打开 <http://127.0.0.1:8765/>。
3. 结束使用时，先保存报告和未完成编辑，再回到启动窗口按 `Ctrl+C` 停止。

也可在 PowerShell 中执行：

```powershell
Set-Location '<你的工程目录>'
python -X utf8 run.py
```

先将 `<你的工程目录>` 替换为实际路径。

服务已在运行时不用再次启动。浏览器页面关闭不代表服务停止；关闭承载服务的启动窗口或重启电脑后，需重新启动。目前没有配置开机自启或 Windows 后台服务。

## 生成实际报告

1. 选择“飞书群聊”，勾选机器人已加入且应用可访问的目标群。
2. 选择日报／周报／月报及日期。个人报告选择已核对的本人发送者；项目报告汇总所选群。
3. 经典结构可直接“同步并生成”。选择其他用途时，点击“配置表达方式”填写材料，再“同步并生成候选预览”。
4. 核对消息依据和人工陈述；候选需点击“保存此预览”后才进入汇报记录，可继续审阅、复制或下载 Markdown。

首次接入应先在获准使用的测试群发送便于核对的消息，再按该消息日期同步和检查结果。新日期是否有消息以实际同步结果为准。

日报／周报／月报按北京时间计算。读取新飞书消息需要网络；仅预览本机已存消息不需要访问飞书。不启用 AI 也可以使用现有本地规则框架。

## 配置与数据放在哪里

| 位置（默认均相对工程目录） | 内容 |
| --- | --- |
| `.env` | 飞书 App ID、App Secret、端口及可选模型设置，仅本机保存 |
| `data/work_summary.sqlite3` | 已同步消息、报告、姓名设置、用途偏好、证据和修订等 |
| `data/operations.sqlite3` | 本工作台操作回执，独立于主库 |
| `data/backups/` | 页面创建的主数据库备份 |
| `start.bat`、`run.py`、`app/` | 启动脚本和程序 |

若 `.env` 或进程环境中设置了其他 `DATA_DIR`，数据位于该实际目录；相对路径按工程目录解析。修改 `.env` 后需重启服务，进程环境变量优先于 `.env`。

当前用途材料尚无跨关页的持久草稿恢复；退出前应完成保存。候选保留在服务内存中，最长有效 30 分钟，且最多保留 20 份；重启后需要重新预览。已确认保存的报告保留在数据库中。

## 备份、更新和迁移

日常可在页面“备份恢复”创建主库一致性备份。它不包含 `.env` 和独立的操作回执库。

完整迁移推荐步骤：

1. 保存报告并停止本地服务。
2. 复制整个工程文件夹，确保包含隐藏的 `.env` 和实际数据目录；默认是整个 `data` 文件夹。不要只复制一个正在写入的数据库主文件。
3. 在新电脑准备 Python 3.11 或以上，确认 `python --version` 可用。
4. 将工程放到新位置。核对 `DATA_DIR`：默认相对路径 `data` 可随工程搬迁；若原先使用绝对路径，需相应调整或搬迁数据。
5. 双击 `start.bat`，打开本机地址，核对历史报告、姓名设置和飞书连接状态。

原有应用凭据可随本人使用的本机工程迁移，通常无需重新创建飞书应用；可读群及权限仍由该应用和所在组织决定。含凭据和消息的数据副本应保存在自己的可信位置，分享代码时不要包含 `.env` 和 `data`。

更新代码前先备份；保留原有 `.env` 及数据目录，再按新版本说明启动。不要使用空数据覆盖原数据。主库迁移在需要时自动备份；恢复主库不会回退独立操作记录。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 检查启动窗口是否仍在运行、是否出现启动失败，以及地址端口是否一致 |
| 提示端口占用 | 先确认本工程是否已经运行；若已运行直接打开页面，避免重复启动。确有其他程序占用时，可将 `.env` 的 `APP_PORT` 改为未占用端口，如 8766，重启后打开对应地址 |
| 找不到 Python | 确保 Python 3.11 或以上可通过 `python --version` 执行，再启动工程 |
| 飞书没有群 | 检查机器人是否加入目标内部群、应用是否已发布且对当前组织可用 |
| 日期范围内没有消息 | 核对实际消息日期、群和所选本人，使用“仅同步消息” |
| 页面仍显示旧版本 | 使用页面“主动更新此页面”；先处理未保存编辑 |
| 候选过期或重启后不能保存 | 重新生成并核对候选；已保存的报告可从汇报记录打开 |

服务只监听 `127.0.0.1`，仅当前电脑访问；手机、其他电脑或公网共享需要单独设计，当前部署没有提供这些能力。飞书读取采用主动请求接口，不需要公网回调地址或隧道。

更多操作见[日常使用说明](USAGE.md)，应用接入细节见[飞书接入指南](FEISHU_SETUP.md)。[下一轮规划](NEXT_ITERATION_PLAN.md)已按用户要求记录为暂不执行。
