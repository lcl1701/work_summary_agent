## 第 9—12 项：本轮交付范围

本轮沿用现有 Python 标准库、SQLite 和原生网页，未新增系统软件、第三方运行依赖或飞书权限。

- **9．本人姓名显示选择**：默认使用已读取的飞书姓名，明确显示名称来源；原有昵称保留，选择“自定义昵称”并保存后可再次启用。本人身份、原始消息、历史报告与来源快照保持原样。
- **10．页面更新与多标签提示**：页面可核对工程版本、服务实例与变更说明。发现旧页面、服务重启或其他标签的数据变化时给出提示，由使用者主动更新；未保存的姓名设置、审阅或自由编辑先提示处理。
- **11．操作记录与变更说明**：本程序的操作回执保存在独立 `data/operations.sqlite3`，不会随主数据库恢复而回退。只保存本程序处理的操作范围、状态、计数及关联标识，不保存消息正文、昵称正文、修订正文、密钥或任意系统命令，也不监控电脑软件安装。
- **12．按条审阅与另存版本**：本地规则稿可逐条确认纳入、分类、改写及人工新增。排除条目仍保留，后续版本可恢复；人工改写和新增明确标记，原始引用范围保留。AI 稿、自由文本修订稿及没有结构化快照的旧稿继续使用自由编辑，避免把原始消息分项误当作当前正文结构。

操作步骤与限制见 [日常使用说明](USAGE.md)。下面保留完整优先级表，便于区分本轮范围与待安排任务。
