## 操作记录与使用边界

`data/operations.sqlite3` 独立于主库备份恢复，只保存固定操作类型、状态及白名单元数据；不保存消息、昵称、审阅说明或修订正文，不保存密钥或任意系统命令，不监控 Windows 软件安装。记录从本版本开始产生，不补写、推断此前电脑行为。迁移自动备份及只读页面查询不作为用户操作补造回执。

未完成记录在服务实际重新启动后标记中断，不能当作成功证明。主库恢复后，某条旧回执关联的报告可能已不在当前库，可通过恢复前安全副本找回。若要迁移整个工作空间，应另行保留独立回执库。

结构审阅仅适用于有结构化快照的规则稿及其结构修订稿；AI 稿、自由编辑稿和无结构快照旧稿继续自由编辑。按条稿重建五个内容章节，不重复输出原事项时间线正文，以免被排除的条目又出现；原稿仍保留完整时间线。原始引用消息数不等于本版纳入事项数，人工新增与改写均需使用者核实。

虚构浏览器数据只在隔离运行目录，未写入真实库或飞书；隔离服务与临时验收标签已关闭，真实工作台继续运行。
